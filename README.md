# 🌐 DOPS IP Scanner

مجموعه‌ای برای **جمع‌آوری، تست و انتشار آی‌پی‌های تمیز (Clean IP) کلودفلر و Fastly**.
آی‌پی‌ها با اتصال TLS واقعی تست می‌شوند و نتیجه هم در همین مخزن ذخیره می‌شود و هم به تلگرام ارسال می‌شود. یک اسکنر تحت‌وب هم دارد که مستقیم روی گوشی کاربر اجرا می‌شود.

🔗 **اسکنر آنلاین:** https://alireza786786.github.io/dops_ip_scanner/
📢 **کانال:** https://t.me/Goodbaye_filtering
💬 **گروه:** https://t.me/CONFIG_V2RAY_VIP

---

## ✨ بخش‌های پروژه

### ۱) اسکن خودکار (GitHub Actions)
- اجرای زمان‌بندی‌شده (هر ۳ ساعت یک‌بار) با GitHub Actions
- دریافت رنج‌های رسمی کلودفلر از `cloudflare.com/ips-v4` (با فهرست پشتیبان اگر دریافت نشد)
- نمونه‌گیری **۵۰ آی‌پی از هر رنج**، تست با **۱۵۰ اتصال هم‌زمان**
- ذخیرهٔ آی‌پی‌های سالم در `outputs/` و ارسال فایل نتیجه به تلگرام

### ۲) اسکنر تحت‌وب (`index.html`)
کاملاً سمت کاربر اجرا می‌شود و به سرور نیاز ندارد.

- 🌍 **منابع:** لیست مخزن، رنج‌های رسمی کلودفلر، بانک آفلاین، آی‌پی‌های پایدار اسکن‌های قبل، لیست دلخواه
- ✍️ **ورود دستی:** تک‌آی‌پی و رنج CIDR
- 🔌 **پورت هوشمند:** حالت خودکار (پورت کانفیگ‌ها یا همهٔ پورت‌های TLS) و حالت دستی با ۶ پورت TLS و ۷ پورت HTTP کلودفلر، تست چندپورتی و پورت دلخواه
- 📊 **نتایج:** تأخیر، نوسان، امتیاز ستاره‌ای و نشان «پایدار 🏆»
- 🧩 **بازنویسی گروهی کانفیگ:** VLESS، VMess، Trojan و SS با حفظ SNI/Host و چهار حالت جایگزینی؛ کانفیگ‌های Reality دست‌نخورده می‌مانند
- 📋 **خروجی:** کپی آی‌پی‌های سبز یا همهٔ آی‌پی‌ها، کپی کانفیگ و ساب، ذخیره فایل
- 🗑 پاک کردن سریع ورودی و خروجی
- 📨 ارسال یا کپی متن آمادهٔ تلگرام
- 📚 آموزش گام‌به‌گام داخل خود برنامه

> اسکنر تحت‌وب فایل `outputs/alive_cloudflare.txt` همین مخزن را به‌عنوان یکی از منابع می‌خواند.

## 🖥 اجرا روی کامپیوتر یا Termux

نیازمندی‌ها: Python 3 و دستور `ping` سیستم (لینوکس یا Termux).

```bash
python main.py
```

منوی برنامه:

| گزینه | کار | فایل |
|-------|-----|------|
| 1 | اسکن کامل Cloudflare | `start.py` |
| 2 | اسکن کامل Fastly | `fastly.py` |
| 3 | تست زندهٔ سریع روی اینترنت گوشی | `test_local.py` |
| 4 | تست ارسال به تلگرام | `sender.py` |
| 0 | خروج | |

### روش تست در اسکنر پایتون
برای هر آی‌پی یک اتصال TLS روی پورت `443` با SNI برابر `cloudflare.com` برقرار می‌شود (مهلت ۲٫۵ ثانیه). آی‌پی‌هایی که وصل شوند با `ping` هم سنجیده می‌شوند. نتیجه بر اساس ping و سپس زمان اتصال مرتب می‌شود و در `outputs/alive_cloudflare.txt` با این قالب ذخیره می‌شود:

```
104.16.1.1 ping=35.2ms connect=48.7ms
```

تنظیمات اصلی (بالای `start.py`): `PORT`، `SAMPLES_PER_CIDR`، `CONCURRENCY`، `OUTPUT_DIR`.

## 🔐 تنظیم ربات تلگرام

توکن و آیدی چت **داخل کد نوشته نمی‌شوند** و از متغیرهای محیطی خوانده می‌شوند:

- `BOT_TOKEN` : توکن ربات
- `CHAT_ID` : آیدی کانال یا گروه

**در GitHub Actions:** مخزن ← `Settings` ← `Secrets and variables` ← `Actions` ← `New repository secret` و دو مقدار بالا را اضافه کنید.

**روی کامپیوتر یا Termux:**

```bash
export BOT_TOKEN="توکن ربات"
export CHAT_ID="@آیدی_کانال"
python main.py   # گزینهٔ 4 برای تست ارسال
```

اگر این دو مقدار تنظیم نباشند، ارسال به تلگرام بی‌صدا رد می‌شود.

⚠️ توکن را هرگز در کد، README یا کامیت نگذارید. اگر جایی فاش شد، از BotFather توکن جدید بگیرید.

## ⚠️ محدودیت‌ها

- **نتیجه به اپراتور و زمان بستگی دارد.** آی‌پی سالم برای یک اپراتور ممکن است برای اپراتور دیگر کند یا قطع باشد. اسکن خودکار روی سرور گیت‌هاب انجام می‌شود، پس لزوماً با اینترنت شما یکی نیست. برای نتیجهٔ دقیق روی اینترنت خودتان از اسکنر تحت‌وب یا گزینهٔ 3 استفاده کنید.
- **اسکنر تحت‌وب فقط زمان پاسخ را می‌سنجد.** سرعت دانلود را اندازه نمی‌گیرد، ستون «کیفیت» بر اساس تأخیر است و «موقعیت» تخمینی است. آی‌پی نهایی را در کلاینت واقعی (مثل v2rayNG) امتحان کنید.
- **پورت‌های HTTP** (مثل 80 و 8080) روی صفحهٔ https در مرورگر قابل تست نیستند.
- پارامتر **Fragment** فقط در کلاینت‌هایی کار می‌کند که از آن پشتیبانی کنند.
- آی‌پی تمیز روی کانفیگی که پشت کلودفلر نیست جواب نمی‌دهد.
- اسکریپت‌ها برای لینوکس یا Termux نوشته شده‌اند؛ روی ویندوز دستور `ping` متفاوت است و ممکن است ping خوانده نشود.
