> ⚠️ این لیست‌ها روی **سرور گیت‌هاب (خارج ایران)** تست می‌شوند و لزوماً روی اپراتور شما سالم نیستند. برای نتیجهٔ دقیق از اسکنر وب یا `test_local.py` روی گوشی خودتان استفاده کنید.
> هر آی‌پی فقط برای کانفیگی کار می‌کند که **پشت همان CDN** باشد.

قالب هر خط فایل (ستون اول همیشه آی‌پی است):

```
104.16.1.1 ping=35.2ms connect=48.7ms jitter=3.1ms colo=FRA ports=443,2053,8443
```

`colo` نقطهٔ حضور سرور گیت‌هاب را نشان می‌دهد، نه شما.

## ✨ اسکنر وب (V14.1 Meridian)

- 🌍 **منبع‌ها:** مخزن (از شاخهٔ data)، cf2dns (کاندیدا)، رنج‌های رسمی کلودفلر و Fastly، پریست Google، CloudFront، Azure، Gcore، ArvanCloud، WARP، بانک آفلاین، آی‌پی‌های پایدار، فهرست دلخواه و آدرس فایل
- 🔌 **پورت هوشمند:** خودکار (پورت کانفیگ‌ها یا همهٔ پورت‌های TLS)، ۶ پورت TLS و ۷ پورت HTTP، تست چندپورتی و پورت دلخواه
- 🧠 **نمونه‌گیری هوشمند:** بلوک‌های /24 موفق هر اپراتور را ۳۰ روز یاد می‌گیرد
- 📊 تأخیر، نوسان، افت، ستاره، نشان «پایدار» برای هر اپراتور جدا
- 🧩 بازنویسی گروهی VLESS، VMess، Trojan، SS (Reality دست‌نخورده می‌ماند) و خروجی **Clash (YAML)**، Base64 و فایل
- 📋 کپی آی‌پی‌های سبز یا همه، 🗑 پاک کردن ورودی و خروجی، 📨 تلگرام
- 🌗 تم روز و شب، 🌐 فارسی و انگلیسی، 📲 نصب به‌عنوان برنامه (PWA) و کار آفلاین

**محدودیت‌های مهم**
- مرورگر فقط **زمان پاسخ** را می‌سنجد؛ آی‌پی نهایی را در کلاینت واقعی (مثل v2rayNG) امتحان کنید.
- ستون «موقعیت» **تخمینی** است. سرعت دانلود از یک آی‌پی مشخص در مرورگر قابل اندازه‌گیری نیست.
- پورت‌های HTTP روی صفحهٔ https قابل تست نیستند.
- **WARP** از UDP/WireGuard استفاده می‌کند؛ تست TLS برای آن معتبر نیست.
- فقط **Cloudflare و Fastly** رنج رسمی زنده دارند؛ بقیهٔ پریست‌ها فهرست ثابت و تأییدنشده‌اند.

## 🤖 اسکن خودکار (GitHub Actions)

- هر **۳۰ دقیقه** اسکن می‌شود؛ پیام تلگرام فقط هر **حدود ۳ ساعت** (۱۷۰ دقیقه) ارسال می‌شود.
- نتایج روی شاخهٔ **`data`** با یک کامیت تازه جایگزین می‌شوند و تاریخچهٔ `main` پر نمی‌شود.
- هر آی‌پی ۳ بار هندشیک می‌شود و یک درخواست تأیید (`/cdn-cgi/trace` برای Cloudflare، هدر Fastly برای Fastly) می‌خورد.
- اگر اسکن خراب باشد (کمتر از ۵ آی‌پی)، لیست قبلی دست‌نخورده می‌ماند.
- cf2dns (ircfspace) فقط به‌عنوان **دانه** خوانده می‌شود و فقط آی‌پی‌های داخل رنج رسمی کلودفلر قبول می‌شوند.

راه‌اندازی قدم‌به‌قدم: [`SETUP.md`](SETUP.md)

## 🖥 اجرا روی کامپیوتر یا Termux

```bash
python main.py
```

| گزینه | کار |
|---|---|
| 1 | اسکن Cloudflare (`start.py`) |
| 2 | اسکن Fastly (`fastly.py`) |
| 3 | تست زندهٔ لیست‌ها روی اینترنت گوشی (`test_local.py`؛ لیست تازه را از شاخهٔ data می‌گیرد و کش می‌کند) |
| 4 | تست ارسال تلگرام (`sender.py`) |
| 5 | تست ریزالورهای DNSTT (`dnstt_scanner.py`؛ با `--domain` دامنهٔ تونل خودتان را هم می‌سنجد) |

برای ارسال تلگرام: `export BOT_TOKEN=...` و `export CHAT_ID=@channel`. برای ارسال فوری (بدون فاصلهٔ ۳ ساعته) `export TG_FORCE=1`.

## 🔐 امنیت

- توکن ربات و آیدی چت را **فقط در Secrets** مخزن بگذارید (`BOT_TOKEN` و `CHAT_ID`)، نه در کد یا README. اگر جایی فاش شد از BotFather توکن جدید بگیرید.
- در اسکنر وب، توکن و کانفیگ‌ها فقط وقتی روی گوشی ذخیره می‌شوند که «به‌خاطر سپردن» را تیک بزنید.
- فهرست‌های بیرونی (cf2dns) هنگام اجرا خوانده می‌شوند و در مخزن کپی نمی‌شوند.
