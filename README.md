> هر آی‌پی فقط برای کانفیگی کار می‌کند که **پشت همان CDN** باشد.

قالب هر خط فایل (ستون اول همیشه آی‌پی است):

```
104.16.1.1 ping=35.2ms connect=48.7ms jitter=3.1ms colo=FRA ports=443,2053,8443
```

`colo` نقطهٔ حضور سرور گیت‌هاب را نشان می‌دهد، نه شما.

## ✨ اسکنر وب (V15.0 Meridian)

- 🚀 **حالت سریع:** یک لمس؛ لیست مخزن را روی اینترنت شما تست می‌کند و بهترین آی‌پی را نشان می‌دهد (تنظیمات شما دست‌نخورده می‌ماند)
- 📷 **QR کانفیگ:** برای انتقال کانفیگ ساخته‌شده به دستگاه دیگر (در v2rayNG «اسکن QR»)؛ رمزگذار QR داخل خود صفحه است و با OpenCV راستی‌آزمایی شده
- 🟢 **نشان تازگی:** سن لیست مخزن را (سبز، زرد یا قرمز) نشان می‌دهد تا اگر اسکن خودکار متوقف شد بفهمید
- 🔒 **حریم خصوصی و امنیت:** CSP، بدون ارسال Referrer، غیرفعال‌کردن تشخیص اپراتور (ipwho.is)، «پاک‌سازی همه‌چیز» و هشدار نسخهٔ غیررسمی
- 👍👎 **بازخورد «کار کرد / کار نکرد»** برای هر آی‌پی: نتایج آینده بر اساس بازخورد واقعی شما مرتب می‌شوند و درصد موفقیت نشان داده می‌شود
- 📈 **روند و الگوی ساعتی:** کدام ساعت‌ها روی اینترنت شما بهتر است (محلی، به‌ازای هر اپراتور)
- 🌐 **نتایج جمعی (اختیاری، نیاز به Worker):** گزارش ناشناس آی‌پی‌های سالم بین کاربران یک اپراتور؛ فقط کاندیدا، همیشه روی اینترنت خودتان دوباره تست می‌شود
- 🧪 **IPv6 آزمایشی** برای کلودفلر، و برچسب «آزمایشی» روی پریست‌های تأییدنشده (Google، Azure، CloudFront، Gcore، ArvanCloud، WARP)
- 🔬 **تست با کانفیگ واقعی (آزمایشی، نیاز به Xray/Termux):** `config_test.py` — آیا آی‌پی واقعاً کانفیگ خودتان را رد می‌کند؟
- ♿ **دسترس‌پذیری:** کنتراست رنگ، نام هر دکمه، اندازهٔ حداقل لمس، ناوبری با صفحه‌کلید
- 🌍 **منبع‌ها:** مخزن (از شاخهٔ data)، cf2dns (کاندیدا)، رنج‌های رسمی کلودفلر و Fastly، پریست Google، CloudFront، Azure، Gcore، ArvanCloud، WARP، بانک آفلاین، آی‌پی‌های پایدار، فهرست دلخواه و آدرس فایل
- 🔌 **پورت هوشمند:** خودکار (پورت کانفیگ‌ها یا همهٔ پورت‌های TLS)، ۶ پورت TLS و ۷ پورت HTTP، تست چندپورتی و پورت دلخواه
- 🧠 **نمونه‌گیری هوشمند:** بلوک‌های /24 موفق هر اپراتور را ۳۰ روز یاد می‌گیرد
- 📊 تأخیر، نوسان، افت، ستاره، نشان «پایدار» برای هر اپراتور جدا
- 🧩 بازنویسی گروهی VLESS، VMess، Trojan، SS (Reality دست‌نخورده می‌ماند) و خروجی **Clash (YAML)**، Base64 و فایل
- 📋 کپی آی‌پی‌های سبز یا همه، 🗑 پاک کردن ورودی و خروجی، 📨 تلگرام
- 🌗 تم روز و شب، 🌐 فارسی و انگلیسی (دکمه‌های آیکونی بالای صفحه، کنار دکمهٔ رفتن به مخزن گیت‌هاب)
- 🌀 صفحهٔ آغازین با کرهٔ چرخان (در بازدید بعدی کوتاه‌تر؛ برای کاربران «کاهش حرکت» ثابت)
- 📲 نصب به‌عنوان برنامه (PWA) و کار آفلاین

**محدودیت‌های مهم**
- مرورگر فقط **زمان پاسخ** را می‌سنجد؛ آی‌پی نهایی را در کلاینت واقعی (مثل v2rayNG) امتحان کنید.
- ستون «موقعیت» **تخمینی** است. سرعت دانلود از یک آی‌پی مشخص در مرورگر قابل اندازه‌گیری نیست.
- پورت‌های HTTP روی صفحهٔ https قابل تست نیستند.
- **WARP** از UDP/WireGuard استفاده می‌کند؛ تست TLS برای آن معتبر نیست.
- فقط **Cloudflare و Fastly** رنج رسمی زنده دارند؛ بقیهٔ پریست‌ها فهرست ثابت و تأییدنشده‌اند.

## 🤖 اسکن خودکار (GitHub Actions + Worker)

- هر **۳۰ دقیقه** اسکن می‌شود؛ پیام تلگرام فقط هر **حدود ۳ ساعت** ارسال می‌شود.
- **اجرای زمان‌بندی گیت‌هاب «بهترین تلاش» است و ممکن است منظم نباشد.** برای اطمینان، `worker/index.js` (رایگان روی Cloudflare Workers) هر ۳۰ دقیقه workflow را از بیرون راه می‌اندازد و اگر لیست چند ساعت به‌روز نشود، به مدیر هشدار تلگرام می‌دهد — جزئیات در [`SETUP.md`](SETUP.md).
- نتایج روی شاخهٔ **`data`** با یک کامیت تازه جایگزین می‌شوند؛ تاریخچهٔ `main` پر نمی‌شود.
- هر آی‌پی ۳ بار هندشیک و یک تأیید واقعی HTTP می‌شود. اسکن خراب لیست قبلی را خراب نمی‌کند.
- اگر `ADMIN_CHAT_ID` بگذارید، اسکن خراب و «دوباره کار می‌کند» به شما اطلاع داده می‌شود.

## 🖥 اجرا روی کامپیوتر یا Termux

```bash
python main.py
```

| گزینه | کار |
|---|---|
| 1 | اسکن Cloudflare (`start.py`) |
| 2 | اسکن Fastly (`fastly.py`) |
| 3 | تست زندهٔ لیست‌ها روی اینترنت گوشی (`test_local.py`؛ لیست تازه را از شاخهٔ data می‌گیرد و کش می‌کند) |
| 4 | تست ارسال تلگرام (`sender.py`) |
| 5 | تست ریزالورهای DNSTT (`dnstt_scanner.py`؛ با `--domain` دامنهٔ تونل خودتان را هم می‌سنجد) |

برای ارسال تلگرام: `export BOT_TOKEN=...` و `export CHAT_ID=@channel`. برای ارسال فوری (بدون فاصلهٔ ۳ ساعته) `export TG_FORCE=1`.

## 🔐 امنیت

- توکن ربات و آیدی چت را **فقط در Secrets** مخزن بگذارید (`BOT_TOKEN` و `CHAT_ID`؛ اختیاری: `ADMIN_CHAT_ID` برای هشدار سلامت)، نه در کد یا README. اگر جایی فاش شد از BotFather توکن جدید بگیرید.
- در اسکنر وب، توکن و کانفیگ‌ها فقط وقتی روی گوشی ذخیره می‌شوند که «به‌خاطر سپردن» را تیک بزنید.
- فهرست‌های بیرونی (cf2dns) هنگام اجرا خوانده می‌شوند و در مخزن کپی نمی‌شوند.
